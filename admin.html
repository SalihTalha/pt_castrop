Ekranı aç

Giriş

Önizleme

Önizleme kaydedilmemiş değişiklikleri de gösterir. Ekranlar yalnızca “Kaydet ve yayınla”dan sonra değişir.

Diller ve yazılar

Seçili diller ekranda sırayla gösterilir; tüm ekranlar aynı anda değişir. Saatler her dilde aynıdır. Tarih, hicri ay ve hava durumu kendiliğinden çevrilir.

Boş bırakılan çeviri yerine Türkçesi gösterilir. Uzun metinler kutularına sığacak kadar küçültülür.

Renkler

Kutular

%0 tamamen dolu kutu demektir. Saydamlığı desteklemeyen çok eski TV tarayıcıları kutuları dolu gösterir.

Arka plan resmi

Resim ekran için hazırlanır (gri ton, saydamlık, arka plan rengiyle karıştırma). TV'lerin bunları kendisinin yapması gerekmez.

Kaydedilecek arka plan, kutular olmadan. Ayarları değiştirdikçe güncellenir.

Hadisler

Hadisler sırayla gösterilir; tüm ekranlar aynı anda aynı hadisi gösterir. Hadis, ekrandaki dil değiştikçe o dilde gösterilir; o dilde metin yoksa Türkçesi gösterilir. Örnek hadisleri yayınlamadan önce kontrol edin.

Namaz vakitleri

Diyanet vakitlerini ezanvakti API'sinden alır (yaklaşık 30 gün, Castrop-Rauxel).

JSON ile ekle

Kabul edilen JSON biçimleri

Tarihe göre nesne (tarih YYYY-AA-GG ya da GG.AA.YYYY):

{
  "2026-11-11": {
    "imsak": "06:10", "gunes": "07:55", "ogle": "12:21",
    "ikindi": "14:27", "aksam": "16:50", "yatsi": "18:28",
    "hicri": "2 Cemaziyelahir 1448"
  }
}

Liste (her gün kendi tarihiyle):

[
  { "tarih": "11.11.2026", "İmsak": "06:10", "Güneş": "07:55", "Öğle": "12:21",
    "İkindi": "14:27", "Akşam": "16:50", "Yatsı": "18:28" }
]

Diyanet / ezanvakti API cevabı da olduğu gibi yapıştırılabilir (MiladiTarihKisa, Imsak, … alanları). Aynı tarih zaten varsa yeni değerler geçerli olur. hicri isteğe bağlıdır.

Kaydet ve yayınla

Değişiklikler GitHub deposuna kaydedilir. GitHub Pages ekranı birkaç dakika içinde günceller. TV'ler yeni ayarları her saat başı kendiliğinden alır (ya da sayfa yenilenince).

Anahtar nasıl alınır?
  1. github.com/settings/personal-access-tokens/new sayfasını açın.
  2. “Repository access” bölümünde Only select repositories seçip yalnızca bu depoyu seçin.
  3. “Permissions → Repository permissions” altında Contents: Read and write verin. Başka izin gerekmez.
  4. Bir son kullanma tarihi seçip anahtarı oluşturun ve buraya yapıştırın.

Anahtar yalnızca bu tarayıcıda kalır ve sadece GitHub'a gönderilir. Paylaşılan bir bilgisayarda “hatırla” seçeneğini işaretlemeyin.
